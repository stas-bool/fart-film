# Пук — карандашный короткометражный луп

Комедийный мультфильм ~10 секунд в технике карандашного скетча:
целые позы-селы (whole-pose cels) + assisted inbetweens, без ригов и спрайтовых
поворотов. Рисуется на Canvas 2D, звук синтезируется Web Audio на лету.

Сюжет: попа осматривается, тужится, пукает — и взлетает как ракета;
зависает, падает, шлёпается, гордится собой. На бис решает пуKNуть ещё
разок миленько — и перестаралась: обкакалась. Шок, оглядка «кто-нибудь
видел?» — и птица-уборщик уносит улику за кадр. Попа возвращается в покой,
цикл замыкается бесшовно (последний кадр = первый).

## Открыть

Просто открыть `index.html` в браузере:

- автоплей и бесконечный цикл; звук включается первым же кликом/тапом
  в любом месте страницы (или плашкой «включить звук» в углу кадра),
  фильм перезапустится с нуля вместе со звуком; где браузер разрешает,
  звук включается сам;
- `?grid=24` — контактный лист, `?frame=85` — конкретный кадр.

## Рендер MP4

Нужны Node.js, системный Chrome и ffmpeg:

```bash
npm i --no-audit --no-fund
node render.mjs index.html            # out/index-final.mp4 со звуком
node render.mjs index.html --grid 24  # контактный лист
node render.mjs index.html --only 85  # отдельный кадр
```

## Устройство

- `index.html` — весь фильм: бриф, генератор поз, ключи, экспозиционный
  лист, облака/пыль/какашка/вонючие волны/птица, сцена, саундтрек.
- `core.js`, `studio.js`, `cels.js` — движок из скилла
  [hand-drawn-canvas-animation](https://github.com/alesha-pro/tools/tree/main/skills/hand-drawn-canvas-animation)
  (alesha-pro/tools); копируется в проект как есть.
- `render.mjs` — офлайн-рендерер скилла (puppeteer-core + системный Chrome,
  каждый кадр снимается с canvas, ffmpeg собирает mp4 и подмешивает саундтрек).

Техника: 21 ключевых поз, замены глаз (блинк/жмурки/счастье/ужас) как
replacement cels, тряска напряжения чередованием двух селов, размещение
корня персонажа зашито в экспозицию (ракетный взлёт/падение), все случайности
сеяны (`rng`/`hash`), метки карандаша стабильны на выдержке.
